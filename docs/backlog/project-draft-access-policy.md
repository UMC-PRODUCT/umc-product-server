# PM 확인 사항: 임시저장 프로젝트 상세 조회 권한

- 상태: PM 정책 확인 대기. 이번 임시저장 개수 제한 해제(#1396)에는 권한 변경을 포함하지 않는다.
- 현재 동작: `GET /api/v1/projects/{projectId}`는 공개 API이며, 임시저장(`DRAFT`) 상태의 프로젝트도 상세 조회를 차단하지 않는다.
- 확인할 내용: 초안을 작성자·담당 PM·운영진 중 누구에게 공개할지, 비회원과 다른 회원의 접근을 제한할지 결정이 필요하다.
- 후속 작업: 정책 확정 후 상세 조회 권한과 접근 허용·거부 테스트를 별도 이슈로 반영한다.
